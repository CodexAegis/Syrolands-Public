Three-weapon numeric combat prototype ​

Design status: Experimental numeric test profile; underlying Modern/Legacy design remains Proposed. Implementation/availability: this profile is not implemented or playable. Verification: documentation and arithmetic review only; no game-feel evidence. Reviewed: 2026-10-09, Batch 06.

Player Guide: weapons and reach · Action schema · Variable triage

Scope and units ​

This is one deliberately small test profile, not final balance, an implementation authorization or a replacement for the existing combat experiment. It tests spacing, tempo, resource pressure, mode differences, counters and readable reach. Every new number on this page is Experimental. Values describe test fixtures, not player progression requirements.

The relative damage index is for comparison and later calibration. It must not be inserted after mitigation or multiplied into local integrity. Existing global/local separation and accepted experimental trauma policy retain authority. Cutting, piercing and blunt emphases below are qualitative; fractures, bleeding and penetration arithmetic are not implemented or selected here. Before gameplay implementation, reconcile action damage with the existing authoritative damage pipeline. Until then, evaluate relative outcomes on paper without claiming those numbers are live.

Shared phase and input rules ​

An accepted action pays stamina once at initiation. Insufficient stamina rejects it. Wind-up (W), active window (A), then recovery (R) run in order; no other action starts before all three finish, including defense. “Immediate defense” means an available manual action bypasses the Legacy swing queue, not that it cancels an already committed action. This restriction is itself a test hypothesis.

  • Modern starts on a valid input; no automatic swing timer blocks it. Recovery gates follow-up inputs.
  • A rejected input causes no damage, stamina charge, buffer or new timer; held input is one intent until released. Count only distinct presses for the spam test below.
  • Revalidate target, LOS and footprint at contact. Single-target actions contact once; arcs contact each eligible target at most once per action. Moving away can defeat an initiated strike.
  • All actions are interruptible during wind-up by voluntary cancellation or loss of required equipment/actor validity; cost is not refunded and full recovery follows. Ordinary damage alone does not interrupt this initial profile. Losing spatial validity causes a miss, not a refunded cancellation. Death terminates the action under existing lifecycle rules.
  • Active phase cannot be voluntarily cancelled. Counter reactions cannot chain from other counters. Counter damage still checks accuracy, range, LOS and armor.
  • Walking is allowed except where the weapon table says planted; running cancels wind-up and pays the same recovery. No speed multiplier or new movement system is selected.

Guard Break treats either active frontal stance as eligible for its guard reduction, but does not trigger that stance's counter. Brace's 35% becomes 17.5%; Riposte's 25% becomes 12.5%. No lingering debuff, shield disable, durability damage or armor bypass is added. Existing shield/armor mitigation still applies separately. For Sweep/Crushing Arc, select at most two valid hostile targets in the footprint at the first active instant: selected target first if eligible, then nearest, stable server identity as tie-break. Facing locks at initiation for planted actions. Footprints must be displayed before impact; if available assets cannot communicate them, block implementation of the affected action rather than grant invisible reach.

Cadence and burst pressure ​

For each offensive action define reference rhythm T = W + A + 1.5 × base R. Use unmodified table durations: no circular feedback from Flow, Familiarity or chain penalties. A Modern follow-up may start once actual phases finish; compare elapsed time since the previous accepted damaging offensive start to that previous action's T. First action has no interval and starts Stable. Feint and defensive actions reset the rhythm to Stable with no streak; they cannot farm Flow. Weapon/mode changes and target changes also reset it.

Actual phase gates always win; a band does not grant permission to bypass recovery. Some lower bands are unreachable with neutral actions; retain them for modified recovery and future mixed-action trials, not as extra attack slots. Three distinct unavailable attack presses within 500 ms while committed trigger Off Rhythm, but create no additional attacks. Server receipt time owns this test; latency tolerance, duplicate transport filtering and accessibility require validation before implementation.

Flow test ​

Only Modern uses Flow. Start Stable. Three consecutive Normal accepted intervals enter Flow for the next action, not retroactively. A rushed/Spam interval or the repeated rejected-input pattern enters Off Rhythm immediately for the triggering accepted action (or the next accepted action after rejected inputs). Three Normal intervals restore Stable; a further three enter Flow. Slightly rushed intervals reset the streak. Strong irregularity also enters Off Rhythm: two consecutive non-pause interval ratios that differ by more than 0.50 (for example 0.75 then 1.30). This is a broad change-of-tempo test, not a perfect-beat requirement. A pause above 1.35T clears Flow to Stable, but does not clear Off Rhythm until either three Normal intervals or 3000 ms without an accepted or rejected attack input. After that idle timeout reset Stable. No exact BPM or narrow perfect-hit window is required.

An action outside Normal loses existing Flow before cost calculation. A Normal interval completing entry still uses the old state; the next Normal action receives Flow benefits. Other candidate fixed/adaptive/personal timing models remain alternatives, not parallel active rules. Consistency changes no random damage distribution in this first profile.

For accepted actions: cost = base cost × Familiarity × chain × rhythm; recovery = base R × Familiarity × chain × rhythm. Round cost upward to whole units and recovery upward to 10 ms; clamp total cost multiplier to 0.80–1.80 and recovery to 0.85–1.60. W is unchanged; stance active tolerance is defined below. Accuracy = fixture 75% + action pp + range pp + Familiarity pp + chain pp, clamped 5–95%. Apply Familiarity only to learned SAs; basics use Practiced neutral factors. No hidden mode damage modifier. Feint/defense use chain ×1 and Stable rhythm economics; they reset Flow on acceptance.

Example: Practiced Longsword Basic Slash has T=1300 ms and 1000 ms minimum phase duration. Starting the next Slash at 1000 ms is Slightly rushed (0.769): cost 11, R=630 ms. Waiting 1200 ms is Normal: cost 10, R=600 ms, or cost 10 after upward rounding and R=570 ms while already in Flow. Stable spear basic T=1550 ms, hammer basic T=2200 ms.

Legacy test ​

Legacy schedules the next offensive initiation from the previous offensive start using that action's T (including an offensive SA or Feint); it never starts before actual recovery ends. Initial target selection waits one basic interval. Invalid target/range conditions delay a swing, never accumulate catch-up swings. When validity returns and the due time has passed, start one action and reschedule from that start. A queued learned/prepared offensive SA replaces one basic action; it is not an extra swing. Empty queue uses the basic. Defense is manual and may start only when phases permit; it cancels the queued offense and schedules the next basic opportunity one interval after defense recovery.

Interval = T × clamp((1 + 0.15 × (1 − stamina/100)) × handling × dexFactor, 0.90, 1.20). Sample stamina before paying the outgoing action. dexFactor = 1 − 0.05 × clamp((DEX − 50)/50, −1, 1). Handling is fixed neutral 1.00 initially, with isolated 0.97/1.03 sensitivity trials; no equipment-quality mapping is selected. Fatigue is derived from stamina here, not another meter. Round interval upward to 10 ms. DEX affects this schedule only, not wind-up/accuracy/damage. STR/INT have no profile modifier.

Round defensive active tolerance to nearest 10 ms, ties upward (Riposte 430/450/470; Brace 1520/1600/1680). Other active windows and all wind-ups remain unchanged. Telegraph refinement changes cue quality only: no invisible cue, delayed cue start or Tactics threshold selected. No extra success RNG for activating a valid SA.

Known SAs remain permanently learned. Prepare up to 5, one slot per SA, no INT scaling. Basics use no slot. Require appropriate weapon, learned knowledge and preparation at initiation. Allow loadout changes only with no selected hostile target, no active/queued action and no hostile action dealt or received for 10 seconds. Changing mode/weapon clears queued SAs and rhythm but never shortens running phases; changes take effect only after recovery. Future INT/preparation complexity effects remain unresolved.

Maintenance test ​

An active day is a UTC date with at least 10 minutes of logged-in, non-idle character activity; a qualifying world or training session may count only after that threshold. This is a provisional accounting convention, not a selected anti-bot detector. Store the last seven such days; calendar absence adds no days and causes no decay. Starting a test character at a chosen tier is fixture setup, not a progression shortcut.

Count per technique. Evaluate once at completion of each active day, only after seven active days have accrued since learning/tier gain. If the current tier's threshold fails, lose at most one tier per evaluation; never lose knowledge. Either column independently meets the threshold; no mixed-use exchange ratio yet. Tier gains are still unresolved; this is retention only. Prepared techniques get no slower decay in this first test. A world use must be a valid, stamina-paid attempt against a meaningful non-cooperative challenge; hit success is not required. A training repetition must finish a prescribed facility exercise, not merely click a dummy. Threat eligibility, idling, collusion, repeated-target caps and automation controls remain implementation blockers. Facilities maintain fluency, not optimal core-skill gain or free discovery. Spell maintenance can test the same count convention later, but spell effects are outside this slice.

Evaluation and unresolved gates ​

Compare modes with identical fixtures, then change one input at a time: neutral versus low stamina; DEX 0/50/100; close versus ideal reach; Learned/Practiced/Mastered; regular versus rushed; successful versus baited defense. Record accepted/rejected inputs, elapsed phase times, stamina, spacing misses, counter attempts and player readability. No numeric success target is established by these paper values.

Unresolved before gameplay work: actual asset reach and facing, authoritative contact/area integration, how relative damage joins existing mitigation/trauma, existing shield composition, transport/latency tolerance, key mapping/accessibility, hostile-target filtering, stamina fixture compatibility, qualifying activity and exploit controls. No new HP/TTK, armor penetration formula, injury type, spell number, stun, item wear or persistent schema. Archery retains no mandatory basic timing minigame, player-controlled Modern release/aim, automatic Legacy release and optional shared SA timing challenges; bows receive no numeric kit here.
