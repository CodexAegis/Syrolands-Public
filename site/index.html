Find your reading path ​

Start with the Player Guide for concise explanations, or explore Game Design for detailed rules, proposals and open questions. Syrolands is a laboratory for a living combat world; described systems are not necessarily available to play.

Combat and character ​

Ordinary attacks remain automatic. Optional advanced interaction combines player judgment with character skill, while the server resolves outcomes. Combat explores local injuries alongside global health. Character progression proposes useful early characters, knowledge and specialization.

Craft, magic and world ​

Professions connect adventuring, learning and making useful things. Item Quality explores workmanship and meaningful equipment loss. Magic proposes discovery, spell knowledge, memory and practice. Living World explores environmental interactions and materials.

Reading feature status ​

Accepted means approved design intent; Experimental identifies a bounded experiment. Proposed mechanics are candidates, and Unresolved questions remain open. Implemented describes existing code within its stated scope, not a promise of current availability or validated balance. Deprecated marks superseded guidance. These distinctions are preserved on each page.
